# 双主持人与脚本模式

在项目中先提交素材，再点击“生成脚本”。素材可以是提示词或原文，在弹窗中明确选择用途。

- **提示词创作脚本**：把素材作为创作要求，围绕主题写台词，提示词最多 5000 字符。
- **保留原文生成脚本**：不调用 LLM，不增加开场白、不改写、不概括；仅切分成每条最多 1000 字符的台词并轮流分配主持人。按顺序拼接台词可恢复已提交原文，支持最长 100000 字符。时长由原文决定，风格和目标时长不影响正文。原文过短无法分配给全部角色时会提示减少主持人。
- **长文本概括脚本**：对原文分段分析、提炼全局大纲、携带前文记忆生成并统一润色，支持最长 100000 字符，最终脚本最多 5000 字符。

“保留原文”指项目中已经提交保存的文本；上传、换行规范化等输入处理发生在这一步之前。过长连续空白无法满足单句非空和长度约束时会明确提示整理空白。

预设主持人 A/B 可单独选择，也可同时勾选。CustomVoice 下 `host_a` 默认映射 `vivian`，`host_b` 默认映射 `uncle_fu`；可用 `TTS_QWEN_HOST_A/B` 覆盖。新账号与已有账号都会补齐缺少的预设，不覆盖自建角色或重新启用停用的角色。Base 克隆模式仍使用用户自己的参考声音。

## 本地模型

保留 `Qwen/Qwen2.5-0.5B-Instruct`，新增 `Qwen/Qwen3-4B-Instruct-2507`。生成弹窗中的选择会写入不可变任务快照，Worker 按实际选择调用 LLM，不依赖任务执行时的页面状态。

下载指定版本（在 llm 独立环境运行）：

```bash
python llm/scripts/download_model.py --model 4b
# 原有小模型
python llm/scripts/download_model.py --model 0.5b
```

4B 固定版本为 `cdbee75f17c01a7cc42f958dc650907174af0554`，默认目录为 `llm/models/Qwen3-4B-Instruct-2507`，可用 `LLM_4B_MODEL_PATH` 覆盖。默认 0.5B 目录仍支持 `LLM_MODEL_PATH`。下载会记录每个文件的 SHA256。也可通过本地控制台“下载 Qwen 4B”按钮续传。

使用现有 llm 环境（transformers 4.57.3），重启 LLM 服务后 `/v1/models` 同时列出两个模型及安装状态。切换模型时释放前一个 LLM 的权重和 CUDA 缓存，避免同时驻留两个 LLM。语音服务是独立进程，仍会占用自己的显存。

更新后在 generation-backend 独立环境运行 `python -m app.bootstrap`，补齐模型目录和预设角色，再重启生成 API、Worker、LLM 和前端。已有登录账号也会在访问时补齐声音预设。Mock 模型和测试音保留用于无权重联调；真实语音应选 CustomVoice 模式下的两位主持人。

为兼容旧客户端，未传 `generation_mode` 的请求仍按文本长度自动选择直接生成或长文概括。新增客户端显式传 `prompt`、`verbatim` 或 `summary`，以及可选的数据库 `model_id`。
