# 当前项目可行性检查（2026-11-15）

## 结论

现有分层架构可运行：React 前端、独立账号 FastAPI、生成 FastAPI、数据库队列 Worker、HTTP LLM/TTS；SQLite 和本地文件存储足以支撑单机开发及功能测试。本轮实测通过真实账号与数据库参与的 M1/M2 短文链路、M1 长文链路及现有无模型测试。

目前可以作为本地联调系统继续开发。不能据此宣称原需求全部交付或真实模型质量已通过：本机默认模型目录没有相应权重，R1/R2 实际推理和听音未执行。

## 阅读范围与发现

检查了根目录及各模块 README、统一基线、完整验收流程、模型与声音克隆说明、CI、前端路由和接口客户端、账号会话/来源校验、生成配置/鉴权/迁移/任务 Worker、LLM/TTS 服务与现有测试、HTTP smoke 和演示脚本。

## 尚需解决的业务与部署条件

- 真实 LLM、CustomVoice 和 Base 的权重、SDK、GPU/内存总占用、首次加载耗时、长文事实准确性与衔接、实际音质，均需专项验收。下载按钮只准备权重，不代表上述条件满足。
- 原需求中的任意语速、TTS 风格控制、脚本前三句试听、逐句重生成和自动重试尚未全部实现。个人密钥、部分模型配置接口仍为 501；应按运行时代码核对范围。
- Base 与 CustomVoice 当前在同一 TTS 进程内互斥；克隆模式需要真实参考录音、准确转写、声音保存及角色绑定，通用自动闭环不会制造替代录音假装通过。
- 当前以本地 SQLite/文件系统为验证基础；多机部署、共享素材、生产反向代理、MySQL 实机、并发容量与运维恢复仍需另验收。控制台用于 loopback 开发，不属于生产运维平台。
- Node.js/pnpm、FFmpeg 和真实模型系统环境是前置依赖。可在页面填写工具/解释器路径；操作系统软件和 CUDA 驱动安装不由业务网页代办。
